# Transcrições publicadas pelo Arquivo Histórico de Jundiaí

Texto extraído, página a página, das transcrições e edições modernizadas que o Arquivo Histórico
Municipal de Jundiaí (Arquivo Histórico Professora Maria Angela Borges Salvadori) publica no
[Acervo Digital](https://jundiai.sismu.app/). Elas servem de referência para alinhar linhas de
treino (Traslado) e para avaliar a leitura modernizada (Posturas de 1831 e contrato de 1763).

Uso acadêmico e sem fins comerciais, com crédito ao Arquivo, conforme a autorização registrada em
[docs/sources.md](../../../docs/sources.md). A licença MIT do código **não** se aplica a estes textos.
Os PDFs, as imagens e o pacote original enviado pelo Arquivo não fazem parte do repositório.
