Usage: ketos train [OPTIONS] [GROUND_TRUTH]...

  Trains a model from image-text pairs.

  The architecture is selected with `--arch`. Options left unset take the
  selected architecture's defaults.

Options:
  --arch [ppocrv6|vgsl]           Recognition architecture family to train.
                                  Auto-detected from --load/--resume
                                  artifacts; only needed when training from
                                  scratch. Defaults shown by --help for shared
                                  options are those of the vgsl family; other
                                  families apply their own defaults to any
                                  option not explicitly set.  [default: vgsl]
  -B, --batch-size INTEGER        batch sample size  [default: 1]
  --pad INTEGER                   Left and right padding around lines
                                  [default: 16]
  -o, --output TEXT               Directory to save checkpoints into.
                                  [default: model]
  --weights-format TEXT           Output weights format.  [default:
                                  safetensors]
  -s, --spec TEXT                 [vgsl] VGSL spec of the network to train.
                                  CTC layer will be added automatically.
                                  [default: [1,120,0,1 Cr3,13,32 Do0.1,2 Mp2,2
                                  Cr3,13,32 Do0.1,2 Mp2,2 Cr3,9,64 Do0.1,2
                                  Mp2,2 Cr3,9,64 Do0.1,2 S1(1x0)1,3 Lbx200
                                  Do0.1,2 Lbx200 Do0.1,2 Lbx200 Do]]
  --variant [tiny|small|medium]   [ppocrv6] Model size. (ppocrv6 default:
                                  small)
  --height INTEGER                [ppocrv6] Input line height. (ppocrv6
                                  default: 96)
  --max-width INTEGER RANGE       [ppocrv6] Maximum line width in pixels after
                                  height-normalization. (ppocrv6 default:
                                  2560)  [x>=1]
  -i, --load PATH                 Load existing file to continue training
  --resume PATH                   Load a checkpoint to continue training
  -F, --freq FLOAT                Model saving and report generation frequency
                                  in epochs during training. If frequency is
                                  >1 it must be an integer, i.e. running
                                  validation every n-th epoch.  [default: 1.0]
  -q, --quit [early|fixed]        Stop condition for training. Set to `early`
                                  for early stooping or `fixed` for fixed
                                  number of epochs  [default: early]
  -N, --epochs INTEGER            Number of epochs to train for  [default: -1]
  --min-epochs INTEGER            Minimal number of epochs to train for when
                                  using early stopping.  [default: 0]
  --lag INTEGER                   Number of evaluations (--report frequency)
                                  to wait before stopping training without
                                  improvement  [default: 10]
  --min-delta FLOAT               Minimum improvement between epochs to reset
                                  early stopping.  [default: 0.0]
  --optimizer [Adam|AdamW|AdamW+Muon|SGD|RMSprop]
                                  Select optimizer  [default: AdamW]
  -r, --lrate FLOAT               Learning rate  [default: 0.001]
  -m, --momentum FLOAT            Momentum  [default: 0.9]
  -w, --weight-decay FLOAT        Weight decay  [default: 0.0]
  --gradient-clip-val FLOAT       Gradient clip value  [default: 1.0]
  --accumulate-grad-batches INTEGER
                                  Number of batches to accumulate gradient
                                  across.  [default: 1]
  --warmup INTEGER                Number of steps to ramp up to `lrate`
                                  initial learning rate.  [default: 0]
  --freeze-backbone INTEGER       [vgsl] Number of samples to keep the
                                  backbone (everything but last layer) frozen.
                                  [default: 0]
  --schedule [cosine|constant|exponential|step|1cycle|reduceonplateau]
                                  Set learning rate scheduler. For 1cycle,
                                  cycle length is determined by the `--epoch`
                                  option.  [default: constant]
  -g, --gamma FLOAT               Decay factor for exponential, step, and
                                  reduceonplateau learning rate schedules
                                  [default: 0.1]
  -ss, --step-size INTEGER        Number of validation runs between learning
                                  rate decay for exponential and step LR
                                  schedules  [default: 10]
  --sched-patience INTEGER        Minimal number of validation runs between LR
                                  reduction for reduceonplateau LR schedule.
                                  [default: 5]
  --cos-max INTEGER               Epoch of minimal learning rate for cosine LR
                                  scheduler.  [default: 10]
  --cos-min-lr FLOAT              Minimal final learning rate for cosine LR
                                  scheduler.  [default: 1e-06]
  -p, --partition FLOAT           Ground truth data partition ratio between
                                  train/validation set  [default: 0.9]
  -u, --normalization [NFD|NFKD|NFC|NFKC]
                                  Ground truth normalization
  -n, --normalize-whitespace / --no-normalize-whitespace
                                  Normalizes unicode whitespace  [default: n]
  -c, --codec TEXT                Load a codec JSON definition (invalid if
                                  loading existing model)
  --resize [add|union|both|new|fail]
                                  Codec/output layer resizing option. If set
                                  to `union` code points will be added, `new`
                                  will set the layer to match exactly the
                                  training data, `fail` will abort if training
                                  data and model codec do not match.
                                  [default: fail]
  --reorder / --no-reorder        Reordering of code points to display order
                                  [default: reorder]
  --base-dir [L|R|auto]           Set base text direction.  This should be set
                                  to the direction used during the creation of
                                  the training data. If set to `auto` it will
                                  be overridden by any explicit value given in
                                  the input files.  [default: auto]
  -t, --training-data FILENAME    File(s) with additional paths to training
                                  data
  -e, --evaluation-data FILENAME  File(s) with paths to evaluation data.
                                  Overrides the `-p` parameter
  -f, --format-type [path|xml|alto|page|binary]
                                  Sets the training data format. In ALTO and
                                  PageXML mode all data is extracted from xml
                                  files containing both line definitions and a
                                  link to source images. In `path` mode
                                  arguments are image files sharing a prefix
                                  up to the last extension with `.gt.txt` text
                                  files containing the transcription. In
                                  binary mode files are datasets files
                                  containing pre-extracted text lines.
                                  [default: xml]
  --linetype [baselines|bbox]     Forces the line type of the training data.
                                  If not set the type is determined
                                  automatically: baselines for XML data, bbox
                                  for path data, and the recorded type for
                                  binary datasets.
  --augment / --no-augment        Enable image augmentation  [default: no-
                                  augment]
  --logger [tensorboard|wandb]    Logger used by PyTorch Lightning to track
                                  metrics such as loss and accuracy.
  --log-dir PATH                  Path to directory where the logger will
                                  store the logs. If not set, a directory will
                                  be created in the current working directory.
  --legacy-polygons               Use the legacy polygon extractor.
  --help                          Show this message and exit.
